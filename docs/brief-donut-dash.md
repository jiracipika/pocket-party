# Brief: Donut Dash (infinite side-scroller)

Fourth Pocket Party game, added after the v1 three-game launch. Follows the
established per-game layout and contracts exactly:

- `core.js` — ES5 UMD, deterministic, injected RNG, `update(dtMs)` in
  milliseconds, `takeEvents()` array events, `CONST` block (same shape as
  Snack Catch).
- `core.test.cjs` — node:test suite (19 tests) covering reset, physics,
  jump budget, gap-safety invariant, i-frames, pickups, determinism.
- `index.html` / `style.css` / `app.js` — browser shell with the standard
  button IDs (`#btnStart`, `#btnPause`, `#btnResume`, `#btnReplay`,
  `#btnMute`), overlays, guarded localStorage, procedural audio, share
  fallback and the `?qa=1` `window.__gameTest` hook. QA state exposes
  `state`, `score`, `hearts`, `time` (pause-frozen elapsed seconds for the
  browser suite's `timer()`), `jumpsUsed`, `onGround`.
- `lens/` — generated by `scripts/build-lenses.cjs`; the shared
  `native/adapter.js` gained a `donut-dash` branch (tap = `game.jump()`,
  player rendered via the `basket` object, obstacles via `itemPool`).

## Rules

- Endless run right; player x is fixed at 90 logical px, world scrolls.
- Jump + one mid-air double jump; budget resets on landing.
- Crates: 42x46 / tall 38x78 / wide 80x44 / double (92px gap). Tall appears
  after 10s, double after 18s.
- Groups separated by `speed * 1.05 + rng * (120 + speed * 0.45)` px —
  always land-then-rejump clearable; unit-tested invariant.
- Pickups: arcs of 3 snacks in gaps, +25 each, never damage.
- 3 hearts; crash costs 1 heart + 1.2s i-frames; hit crate marked `hit`.
- Speed 240 -> +6/s -> cap 520. Score = floor(px / 12) + 25 * pickups.
- `endRun()` exists so the shell's "End Run" button can finish honestly
  (no round timer to expire).
